# 3YDL3-V11-r3

三层全局导航规划研究项目。L1选择路线，L2生成二维栅格参考路径，L3生成三次B样条并执行连续曲率、车体碰撞、交通与端点严格校验。输出沿用`PlanResult.points`的`x/y/yaw`字段，以及`N×3 float64`路径表示。

[单版本结果](../../docs/3ydl3_v11_r3/RESULTS.md) · [验收摘要](ACCEPTANCE.json) · [300条逐次统计](report/requests.csv) · [发布文件校验](metadata/PUBLICATION_MANIFEST.json)

## 项目内容

包含算法源码、配置、原生库、Python求解器依赖、功能测试、运行入口和本版结果。`runtime_dependencies/`提供所需的基础代码及库，第三方许可保留在相应目录。算法源码、配置及原生库按验收版本保留；历史性能实验报告和独立对比脚本不纳入发布。

## 运行条件

地图栅格、语义地图、原固定Q、MAPS.json及逐案路径/范围数据不随Git分发，需要单独取得原地图与配套绑定。需要Linux x86_64、Python3.10、ROS2 Humble/Nav2及相应科学计算环境。

原脚本保留测量时的绝对路径，本目录不是任意路径下即开即用的安装包。请在独立复现环境恢复原路径或适配路径，勿覆盖本机冻结工作区；本次没有验证新机器部署。原机导航入口为：

```bash
./run.sh --map-id <地图ID> --output <新输出目录>
```

在仓库根目录校验发布文件（无需地图或ROS）：

```bash
python3 tools/verify_3ydl3_v11_r3.py
```
