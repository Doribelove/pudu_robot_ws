## 算法与输出

L1路线选择、L2二维栅格参考路径、L3三次B样条与信赖域SQP；保持真实代价图ACK、连续曲率/车体证书和完整交通终验。结果沿用`PlanResult.points`的`x/y/yaw`字段和`N×3 float64`路径表示。

先精确规划，失败后才允许起终点分别在0.20m、±30°内回退，最小转弯半径仍为0.40m。正式300次为297次精确成功和3次容差成功，不能写成原精确端点300/300。验收范围为静态完整规划与指定受控回放。

## 数据与复现边界

按用户要求，本次不上传十张地图：原始占据栅格、语义地图、原固定Q文件、MAPS.json、逐案路径/拓扑/范围栅格、缓存与重复源码快照均不纳入。统计CSV、箱线图、代码/输入哈希和验收记录保留；原始资料仍在本机冻结工作区。

原脚本保留测量时的绝对路径，不能将本目录宣传为任意路径下即开即用的发行包。需要Linux x86_64、Python3.10、ROS2 Humble/Nav2及科学计算依赖，并单独取得原地图/Q和绑定登记。`runtime_dependencies/`保存基础V1/r11的代码、配置和库；系统ROS及其余系统安装不随Git分发。第三方许可保留在相应目录。

原机入口为`./run.sh --map-id <原MAPS.json中的ID> --output <新输出目录>`。请在独立复现环境恢复原路径或审慎适配路径，不能覆盖现存冻结版本；本次没有重跑导航或验证新机器部署。

只校验本次发布完整性，无需地图或ROS：

```bash
python3 tools/verify_3ydl3_v11_r3.py
```

该命令在仓库根目录执行。`metadata/EXTERNAL_INPUTS.json`仅列地图ID和输入指纹，不包含地图内容。
