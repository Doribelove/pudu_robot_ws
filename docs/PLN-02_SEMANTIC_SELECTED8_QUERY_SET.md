# PLN-02 语义地图对比实验 8 组起终点

## 结论

在导师提供的 `SemanticMapV1` 上，已冻结一套用于后续 2A-V2 对比实验的 8 组起终点：`semantic_compare_selected8_r2_v1`。

这 8 组的 16 个端点均位于 footprint-safe 自由空间，端点到自由空间危险边界（障碍物或未知区，按机器人 footprint 后的保守口径）的距离为 **1.558–2.779 m**，均高于本次设定的 **1.5 m** 门槛。拓扑路线集中在 **44.54–45.63 m**，便于减少路径长度差异造成的混杂。

![8 组起终点在语义地图上的分布](../private_data/pudu_wanda_3f/query_sets/semantic_compare_selected8_r2_v1/selected8_query_overlay.png)

图中 `nS`、`nG` 分别表示第 n 组的起点和终点，彩色曲线为筛选阶段使用的拓扑连通路线。8 组分布覆盖地图不同区域，并包含车道双向、减速带、路口直行/转弯、车道与车位区切换、车位区内部等场景。

## 筛选规则

1. 端点中心到 footprint-safe 自由空间边界至少 1.5 m；边界同时包含占据栅格和未知栅格，因此比只看障碍物中心距离更保守。
2. 起终点 footprint 合法、属于同一可通行连通分量，且端点不落入硬禁行或禁停终点区域。
3. 起终点朝向取所选拓扑路线的起始/终止切线方向，降低朝向不合理导致的 Hybrid A* 偶发失败。
4. 目标拓扑长度为 30–60 m；最终 8 组进一步收敛到约 45 m，使后续路径质量和耗时比较更公平。
5. 先生成 16 组候选并以 E0、E4 实跑，最终保留场景互补且无需放宽即可成功的 8 组。
6. 本轮只验证静态地图，不含动态障碍物。

## 实跑验证

验证版本：

- `architecture_id: 2A-V2`
- `implementation_revision: r2-direction-ack-latency`
- E0：旧 selector，语义只审计、不影响规划
- E4：完整 2A-V2 语义规划与 graceful relaxation
- 每组、每臂：1 次预热 + 3 次正式测量
- 独立 ROS domain：152

正式测量结果：

| 指标 | E0 | E4 |
|---|---:|---:|
| 成功率 | 24/24 | 24/24 |
| R0 成功 | 24/24 | 24/24 |
| P50 请求耗时 | 1.542 s | 1.788 s |
| exact costmap ACK | 24/24 | 24/24 |
| 碰撞违规 | 0 | 0 |
| 运动学违规 | 0 | 0 |
| 硬语义违规 | 0 | 0 |
| 禁停终点违规 | 0 | 0 |

E4 检查了 4,333,464 个软代价栅格，exact mismatch 为 0。全部 E4 请求都在 R0 成功，没有依赖 R1–R4 放宽。正式成功路径长度为 **35.881–45.645 m**。

需要区分两个距离指标：本报告的 **1.558–2.779 m 是端点净空**，用于保证起终点不贴障碍；规划路径在途中可以正常经过较窄通道，其最小净空可能更小，但所有路径均通过 footprint 碰撞检查。

## 使用建议与边界

这套 8 组查询是有意按“净空足、成功率高”筛选出来的，因此适合比较：

- E0–E4 的路径形态、长度、耗时；
- 车道靠右、停车区靠中、减速带软代价是否产生预期效果；
- 同一查询在不同实现版本间是否出现回归。

它不适合单独用来宣称规划器在未知查询上的总体成功率，因为存在筛选偏差。正式结论建议同时保留原冻结 8-query 难例集作为挑战/回归集；本套 clean set 与难例集分别回答“语义效果是否可比”和“困难场景是否鲁棒”。
