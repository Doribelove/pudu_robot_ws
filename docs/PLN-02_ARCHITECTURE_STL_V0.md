# PLN-02 STL-V0 独立语义联合规划架构

`architecture_id: STL-V0`，首个实现 `stl-v0-r0`。这是由用户于 2026-09-09 明确命名并授权建立的新主线，不是 3D、2A 或原 Portal 方案的版本升级。当前处于独立离线研究阶段。

## 1 架构定义

**语义规则＋可行空间集合＋路线与轨迹联合求解。**

节点表达“任务进度 × 可行区域”，连接保留可调过渡空间。路线候选的优劣由连续求解后的轨迹代价和可行性决定；过渡位置及朝向不提前固定。

| 部分 | STL-V0-r0 实现 |
|---|---|
| 规则 | 有界到达、顺序访问、始终安全、禁用标签、区域半空间与方向锥 |
| 空间 | 原分辨率安全像素派生的保守轴对齐凸区域；受控场景可直接给定凸区域 |
| 离散求解 | 任务乘积图、有界 Yen 候选枚举 |
| 连续求解 | 三次 Bézier，优化接口位置、共享物理切向速度和分段时间；SLSQP |
| 可行性 | 控制点凸包含、连续曲率界、精确端点、C1 拼接与时序见证；实图独立车体碰撞复核 |
| 选择 | 对已完成连续求解且通过检查的候选比较目标值 |
| 失败 | 输出明确拒绝／预算／有限覆盖失败；不借用旧架构返回成功 |

该实现借鉴 [STL–GCS](https://arxiv.org/html/2605.23240v1) 的任务与连续空间联合思想，**不是其凸松弛算法的完整复现**。不声明连续空间完备性、全局最优或完整 STL 支持。

## 2 与现有架构的边界

代码根目录：`research/stl_v0/`；独立 Python 包 `stl_v0`、独立入口 `run_stl_v0`、独立协议 `STL-V0-STATIC-RESEARCH-R0`，输出统一写入 `experiments/stl_v0/` 的新目录。

核心没有 3D／2A／旧拓扑骨架／Smac／Nav2／ROS 运行时导入。现有生产 resolver、factory、launch、默认配置和安装空间不变。包内 `COLCON_IGNORE` 防止进入现有默认构建。

共享的是原始数据和物理实验条件，不能把历史规划路径或缓存作为新算法生成结果。所有请求绑定实际源码和输入哈希，运行中发生漂移则拒绝。

这里的 3D 指现有动态三层架构系列，不是三维坐标。STL-V0-r0 当前研究静态二维地图上的 SE(2) 参考轨迹，没有引入动态避障、局部控制或三维感知。

## 3 独立实验合同

地图保持 0.05 m/cell；padded 车体半长／半宽为 0.265/0.225 m，禁止倒车与原地旋转，最小转弯半径 0.40 m。它们是本课题实验约束，不能表述为 Jackal 固有物理极限。

受控场景验证 STL-V0 的规则及联合求解机制；导师地图默认使用冻结 selected8，并区分原始语义绑定、物理预检和完整 R2 语义验收。未实现或未运行的完整 R2 项输出 null／NOT_EVALUATED，不能记通过。

## 5 r1 独立研究进展（2026-09-10）

r1 实验实现为 `stl-v0-r1`，协议为 `STL-V0-STATIC-RESEARCH-R1`；首版 r0 的历史结果保留。

r1 新增安全像素覆盖补全与接缝桥接、从原图新生成的稀疏/宽区域/完整覆盖候选族、语义半空间接口检查、真实车道局部靠右实验及过渡位姿配对消融。覆盖连通保证仅限有限 ROI 内保守安全栅格的四连通关系。

最终 selected8 联合优化为 7/8，固定位姿为 4/8，三次同进程重复一致；局部靠右规则联合组 3/3 通过物理与连续语义检查。完整 R2 尚未验收。详见 [r1 图文实验报告](PLN-02_STL_V0_R1_COVER_AND_SEMANTIC_STUDY.md)。

## 6 r2 性能与曲线细分进展（2026-09-10）

当前实现为 `stl-v0-r2`，协议为 `STL-V0-STATIC-RESEARCH-R2`。新增空间扫描索引、共享几何邻接、按需任务图与内容哈希准备缓存；覆盖缓存绑定精确查询/ROI，新查询首次仍需构造。所有缓存都不包含历史路线或轨迹。

在基础候选全部失败后，可将每区域一段曲线细分为两段，最多尝试两条原路线，仍共用 30 s 请求预算。selected8 物理通过数从 7/8 提升到 8/8，三次重复一致；局部硬靠右实验保持 3/3 通过。

同轮基线规划 P50 为 4.85 s；禁用细分的纯性能对照首次几何构图 2.52 s、缓存命中 1.42 s，候选、有效性和成功目标值均保持。缓存命中并启用细分后 P50/P95 为 1.36/6.27 s；08 新增可行结果带来尾部时间开销。规划计时不含地图、覆盖、车体复核及绘图。完整 R2 语义与生产验收仍未完成。

详见 [r2 图文实验报告](PLN-02_STL_V0_R2_PERFORMANCE_AND_REFINEMENT.md)。冻结源码、输入哈希、96 次物理请求与独立配对核验见 `experiments/stl_v0/stl_v0_r2_verified_20260910/`。
