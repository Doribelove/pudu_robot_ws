# 三层架构与事件恢复

| 层次 | 职责 | 实现入口 |
|---|---|---|
| L1路线层 | 根据区域、方向和交通规则选择通道 | `base/runtime/base/src/three_yd_v3`、`three_yd_v4` |
| L2几何层 | 在选定域中生成几何参考；H-A使用原生A*重搜，H-I在同域增量更新D* | `base/src/three_yd_v13`、`base/native` |
| L3轨迹层 | 三次B样条/SQP连续优化，检查车体、曲率、交通和端点 | `base/runtime/base/src/three_yd_v5` |
| 事件接口 | 原子提交当前位姿和障碍，管理路径有效性及恢复 | P6使用基础`service.py`；P7-r1使用`src/three_yd_v13/service.py` |

## P6：障碍附近局部扩域

1. 在当前L2域修复参考线。
2. 短参考线的提示域不连通时，在相交障碍中心增加半径5m的局部中性搜索区域，随后重试L2。
3. 扩域仍失败时，进入原走廊、L1重选、全图引导和端点容差恢复。
4. L3生成完整轨迹，经终验后返回点列；失败则撤回新路径。

该扩域分支用于非语义中性区域，保留物理障碍和语义通行规则。`p6_hint.py`以ContextVar管理请求策略与阶段，缓存键包含域阶段；换域时创建新的L2状态。

## P7-r1：障碍反馈L1与长车道分段

语义区域内的障碍可能切断入口与出口。`runtime_l1.py`按当前障碍构建运行时连通组件，将长车道的不同片段作为独立节点，交给L1选择路线。这样可以离开原车道，经其他道路后回到另一片段。

输出映射回原语义区域ID，并保留运行时片段序列。方向、禁转和停车归属规则参与后续检查。新L1域使用一次完整候选恢复调度；其他事件沿用P6/P5恢复流程。请求结束时释放临时图，障碍清除后恢复静态图。

## 运动与预算

车体0.53×0.45m，前进运动，最小转弯半径0.40m。通道折返通过符合当前朝向的前进掉头连接实现。精确求解失败后可使用双端0.20m/30°容差。

全请求预算30s，L3累计预算15s，各候选与换域操作共享计时。约0.6s是常规精确端点L3阶段的时间片；P7-r1运行时新L1域直接执行完整候选恢复。
